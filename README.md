# EASE AND TRAVEL – Luxury Mobility & Travel Experience

A premium, production-ready travel and mobility website for **EASE AND TRAVEL**, offering luxury car rentals, flight/train/bus ticket bookings, and 5-star hotel reservations in New Delhi, India.

---

## 🌟 Highlights

- **Luxury Brand Aesthetic:** Blending the bespoke luxury editorial design of *Happy Luxe Travels* with the multi-service booking workflows of *Better Holidays*.
- **Extracted Brand Palette:** Signature Imperial Navy (`#00102A`) and Champagne Gold (`#DEA949` / `#FAC55F`) derived from the official business logo.
- **10-Vehicle Premium Fleet:**
  - Toyota Prius (Premium Sedan)
  - Toyota Camry (Executive Sedan)
  - Mercedes-Benz E-Class (Luxury Executive Sedan)
  - Tesla Model S (Electric Flagship Sedan)
  - Mercedes-Benz S-Class (Luxury Flagship Sedan)
  - Tesla Model Y (Electric Luxury SUV)
  - Range Rover (Luxury SUV)
  - Mercedes-Benz V-Class (Luxury MPV)
  - Toyota Alphard (Royal Luxury MPV)
  - Toyota Commuter (Passenger Van)
- **Interactive Vehicle Modal:** Dual-view exterior & interior cabin inspection with direct WhatsApp inquiry routing.
- **Hybrid Quick Booking Bar:** Multi-service tabs for instant travel enquiries right below the hero.
- **Direct Enquiry Desk:** Validated with React Hook Form + Zod, automatically formatting structured booking inquiries to WhatsApp (+91 8750330196).
- **Interactive Lightbox Gallery:** Six-category asymmetric grid with keyboard controls.
- **SEO & Schema:** Semantic markup, Open Graph, Twitter cards, and `schema.org/TravelAgency` JSON-LD structured data.

---

## 🛠️ Tech Stack

- **Framework:** React 18+ with TypeScript
- **Bundler:** Vite 6
- **Styling:** Tailwind CSS with custom theme extensions
- **Validation:** React Hook Form + Zod + `@hookform/resolvers`
- **Icons:** Lucide React

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
